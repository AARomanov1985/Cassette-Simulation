# BASF LH Extra C90

BASF LH (Low Noise High Output) Extra C90 is a classic German Type I ferric cassette tape from the late 1970s and 1980s.

## Sound Character

It has a warm, vintage analog sound. The bass response is full but slightly soft. High frequencies roll off smoothly above 13 kHz.

Tape hiss is noticeable but not overwhelming. You get mild wow and flutter from normal transport wear. It gives music a cozy, nostalgic 1980s home audio feel.
