# Sony CHF90 (1978)

Sony CHF90 was the 90-minute variant of Sony's popular 1978 CHF normal bias cassette line.

## Sound Character

Because 90-minute tape is thinner, it has slightly more mechanical pitch drift than the CHF60.

The sound is mid-heavy with a prominent treble cut above 13.5 kHz. Tape hiss is moderate. It adds a subtle pitch wobble and classic cassette color to synthwave and retro ambient audio.
