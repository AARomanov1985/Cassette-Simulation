# Sony CHF60 Type I Normal (1978)

Sony CHF60 was Sony's mainstream Type I normal bias cassette line in the late 1970s. The 60-minute version uses a thicker tape substrate than 90-minute tapes.

## Sound Character

It produces a warm, focused mid-range with boosted low-mids around 250 Hz. High frequencies are softened above 13.5 kHz.

Background noise is moderate. Pitch stability is very consistent because of the thicker tape backing. It sounds organic and smooth, perfect for classic 1970s pop and spoken word.
